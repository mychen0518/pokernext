# 09: 雙驗證與唯一 UUID

**What to build:** 人工核准後才發送註冊 Email 與簡訊驗證；手機驗證、Email 驗證、人工核准三者獨立成立後，系統建立唯一正式會員並發一個終身 UUID。任何重送、重試、並發都只能產生一位會員。

**Blocked by:** 08（審核工作台：核准／補件／拒絕、版本綁定、重複提示）

**Status:** ready-for-agent

- [ ] 核准前不發送任何驗證通知；核准後才發（一正一反）
- [ ] 假通知埠注入送出失敗時，審核狀態不變，申請人能重新索取驗證
- [ ] Email 連結 24 小時失效；開啟連結不算完成，必須再主動按確認（模擬郵件掃描器開啟連結，驗證狀態不變）
- [ ] 三條件各自有效期，其中一項過期只需重做那一項
- [ ] 三條件齊備時建立會員與 UUID；重複點擊、重送驗證、回報重試都回傳同一 UUID
- [ ] 資料庫層唯一約束：兩份同身分申請並發核准（併發測試）只建立一位會員，另一份回既有結果
- [ ] UUID 與申請編號、Lead ID 不同且可互相追溯

**Notes:** G02：簡訊／Email 供應商送達回報語義未定，用假通知埠。
