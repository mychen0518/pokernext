# 34: 上線切換：平行試跑、既有行程接管、上線 Checklist 與同版操作手冊

**What to build:** Platform admin 在獨立測試環境以至少 7 個活動日平行核對期初、每日、重複、更正、錯會員／錯行程與模擬住宿結算；試跑完成後取正式新截止點的期初，測試帳務不搬到生產；上線時有真實未完旅程的客戶先本人註冊取得 UUID，再由接管流程核對天城會員號、既有行程與有效住宿 PDF；琪琪對齊既有現金事實；有一份含停止條件的上線 Checklist 與同版繁中／英文操作手冊。

**Blocked by:** 24（天城每日積分 Excel 匯入、差額預覽、核准入帳與配對）、26（玩家確認結算、正式扣分、住宿兌換核對單與天城「雙方已對齊」）、27（天城押金：應付／實收／應退／實退四軸與差異案件）、30（天城合作端現場 UI：在島玩家頁、離境與未完成核對頁、接送頁、差異提出）

**Status:** ready-for-agent

- [ ] 平行試跑腳本覆蓋期初、每日、重複、更正、錯會員／錯行程、模擬結算六類，至少 7 個活動日
- [ ] 試跑後以正式新截止點建期初；日更只涵蓋未入期初資料；測試環境帳務不存在於生產
- [ ] 接管流程：客戶未完成雙驗證取得 UUID 前無法接管（一正一反）；接管核對天城會員號、既有行程、有效住宿 PDF
- [ ] 接管既有現金事實時不重收、不重扣、不把歷史總分當新業績
- [ ] 上線 Checklist 每步含入口、來源、欄位範例、操作、預期、停止條件、失敗處理、實際結果、證據、執行人、核准人與版本
- [ ] 權限漏洞、錯帳、重複扣退、必要確認失效、核心復原失敗為阻擋項，Checklist 不允許勾選略過
- [ ] 操作手冊版本與介面版本綁定；版本更新只提醒、不阻擋使用

**Notes:** G17：正式上線截止／時區與真實期初由天城交付；G21：最終截圖與各角色驗收證據。
