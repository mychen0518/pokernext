# 33: 邊緣防護：私人路由 no-store、來源保護、Webhook 簽章、攔截錯誤回報

**What to build:** 所有私人文件與私人資料回應明確旁路 CDN 快取並帶 no-store；API 端點不回傳互動式 HTML 挑戰；外部供應商 Webhook 以簽章驗證；防護攔截後回報不含敏感內容的錯誤與可查核的事件識別，並引導使用者查詢原操作結果而不是重交現金或重新匯入；以中介層模擬 Cloudflare 邊緣測試誤擋、故障、挑戰、回應中斷四種情境。

**Blocked by:** 05（文件保護核心：信封加密／KMS 埠、HMAC 查找索引、限時查看、故障暫停）

**Status:** ready-for-agent

- [ ] 所有私人路由回應帶 no-store 與 cache bypass 標頭；公開活動媒體按公開資產規則（一正一反）
- [ ] API 端點在被挑戰時回結構化錯誤而不是 HTML 挑戰頁
- [ ] Webhook 缺簽章或簽章錯誤被拒；重放同一簽章被拒
- [ ] 來源 IP 在台灣／韓國以外不被拒
- [ ] 模擬邊緣故障時只暫停受影響功能，不存在任何無防護的備用後端網址
- [ ] 攔截後的錯誤回應含事件識別、不含敏感內容；前端引導查詢原操作結果
- [ ] 正式後端沒有可繞過防護的公開入口（以拓撲測試證明只有一條進入路徑）

**Notes:** G23：實際 Cloudflare 帳戶、來源拓撲、限流規則與例外期限未定；本票不宣稱已部署。
