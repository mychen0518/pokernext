# 24: 天城每日積分 Excel 匯入、差額預覽、核准入帳與配對

**What to build:** 管理者每個活動日上傳一份天城固定格式 Excel（批次資訊＋每日明細），經格式／重複／會員與行程檢查後看到逐列差額預覽（新增／未變／更正／缺列），授權管理員核准後整批入帳；以對照表配對會員、以活動日期配對行程；數值更正走差額入帳、識別更正走撤銷＋重建；玩家在積分實際改變時收到通知。

**Blocked by:** 15（行程申請、行程編號與版本、草稿、同行者）、23（期初積分導入與會員積分頁）

**Status:** ready-for-agent

**UI:**
- Surface: 管理端
- Page type: DESIGN.md §3.2 作業頁：上傳 → 差額預覽 DataTable → 核准
- Reference: `docs/design/references/partner-overview.png`（DataTable）
- Prototype: `#/admin/points`；actions `approveImport`
- Components: Button/secondary（上傳每日 Excel）、Card（批次：活動日、上傳人、格式／防重檢查結果）、Badge 四色計數（新增 success／未變 neutral／更正 warning／缺列或未配對 danger）、DataTable/dense（會員編號、會員、配對行程、前值、本次、差額、判定；列色依判定）、Button/primary（授權核准整批入帳）、Button/secondary（處理未配對列）、Modal（人工指定會員／行程並留理由）
- States: 有阻擋錯誤 → ResultBanner/error 且核准按鈕 disabled；已入帳 → dot/success + 時間；重複檔 → ResultBanner/info「辨識為重複，未入帳」

- [ ] 格式版本不符、同版本不同內容的重複檔被拒；相同檔案重傳被辨識為重複、不重入帳
- [ ] 預覽逐列標示新增／未變／更正／缺列，差額以「已入帳當日新增」為基準，不以目前餘額計算
- [ ] 有阻擋錯誤的檔案整批不入帳，沒有同檔部分成功（一正一反）
- [ ] 原值 10,000 更正為 12,000 只入 2,000 並保留原值；缺列不刪帳、不當零；確定不成立須明列 0 及理由並經第二人核准
- [ ] 「會員／活動日期／行程」識別更正必須撤銷錯誤歸屬並建立正確紀錄，不能直接改欄位；改動已入帳數字需另一位授權管理員核准
- [ ] 配對：對照表 → UUID，活動日期 ↔ 行程日期 → 行程；多候選、零候選、資料不足時要求人工指定並留理由，不自動選最近一趟、不自動建空行程
- [ ] 酒店入住／場館到場只作查核輔助，不是入帳門檻；已確認本次活動後的晚到積分仍歸原行程並增加餘額
- [ ] 同 (venue, venue_member_no, activity_date) 為邏輯紀錄；換號期間同日資料不自動相加
- [ ] 只在積分實際改變並成功入帳時發通知（含新值與原因）；未變／重複／失敗不發
- [ ] 轉派後接手人 B 看不到 A 歸屬期間該客戶的逐筆積分明細；會員本人永遠看到完整歷程
- [ ] 積分明細可直接進入問題回報，自動帶入行程、活動日與帳目參照
- [ ] 差額預覽每列的判定同時有文字與列色；有任何阻擋錯誤時「核准整批入帳」不可按

**Notes:** G06：天城真實範本與活動日切點未定，用去識別化樣本檔（正常／更正／重複／錯會員四種）。G12：交付時間不作正式排程。
