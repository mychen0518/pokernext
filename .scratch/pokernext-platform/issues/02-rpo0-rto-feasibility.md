# 02: RPO 0／跨區 RTO 2 小時選型可行性驗證

**What to build:** 以第 01 票選定的儲存與雲端拓撲，證明「已成功保存的正式資料、未送出草稿與保留期內原始檔案」在單節點／單 AZ 與整區中斷下都不會遺失，且核心能在目標時間內恢復。這是 spec 明文的選型硬約束：驗證未過前不擴展功能。

**Blocked by:** 01（專案骨架與測試基礎設施）

**Status:** ready-for-agent

- [ ] 有一份可重現的演練腳本：寫入一批正式資料、一份未送出草稿、一份原始檔案後，模擬單 AZ 故障，核心恢復時間 ≤ 30 分鐘且三類資料零遺失
- [ ] 同一腳本模擬整區中斷，核心恢復時間 ≤ 2 小時且三類資料零遺失（含跨區）
- [ ] 備份具備至少 7 天 PITR ＋ 90 天每日備份，且備份的刪除權限與一般寫入權限分離
- [ ] 保護鏈斷裂（跨區複寫不可用）時，寫入不回報成功：受影響寫入等待或標為「結果待查」，有測試證明
- [ ] 演練的原始量測與結論寫成文件；若選型不能達標，改選型並重跑，而不是調低目標

**Notes:** G14：正式環境的達成證明需真實雲端演練；本票以測試環境證明可行性，不宣稱供應商 SLA 等於本產品達成。
