# 11: 通訊綁定與通知偏好

**What to build:** 會員綁定 LINE／WhatsApp／Telegram（每平台一個），把服務通知與推廣偏好分開設定並能一次全部停止推廣；管理者看到每則通知的「已送出／失敗／客戶明確確認」三種狀態。

**Blocked by:** 10（會員 OTP 登入、換證與人工帳號恢復）

**Status:** ready-for-agent

- [ ] 加好友、聊天、正式綁定是三個獨立狀態；加好友不會產生綁定
- [ ] 同平台已綁一個帳號時再綁被拒；該外部帳號已綁到別的會員時被阻止覆蓋（一正一反）
- [ ] 服務通知與推廣偏好分開；「全部停止推廣」後所有推廣管道都不送，服務通知照送
- [ ] 退訂某管道後，同一則推廣不會改用另一管道補發
- [ ] 每則通知記錄已送出／失敗／客戶明確確認，三者不互相推定；假通知埠注入失敗時狀態為失敗

**Notes:** G04：實際供應商 API 與送達語義未定，本票以假通知埠實作；不依賴 Respond.io。
