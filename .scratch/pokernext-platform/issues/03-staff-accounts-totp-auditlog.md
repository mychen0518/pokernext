# 03: 工作帳號邀請、密碼＋TOTP 登入、備援碼與 AuditLog

**What to build:** Platform admin 能邀請一位工作人員，對方憑七天單次邀請完成設定（密碼＋TOTP＋8 組備援碼）並登入；每一步都在 AuditLog 留下紀錄。這是所有員工端、管理者端、天城端帳號的共同基礎。

**Blocked by:** 01（專案骨架與測試基礎設施）、02（RPO 0／跨區 RTO 2 小時選型可行性驗證）

**Status:** ready-for-agent

- [ ] 初始 Platform admin 只能經一次性初始入口建立；完成後入口關閉，且沒有任何工程師後門可再建帳號
- [ ] 邀請連結七天內可用一次；過期或已用的連結被拒絕並留下稽核紀錄
- [ ] 登入需密碼＋TOTP；備援碼每組只能用一次；用備援碼登入會留下稽核紀錄
- [ ] 受限恢復流程：遺失 TOTP 的人員只能由另一位 Platform admin 核准重設，不能自助
- [ ] 正常繼任不會移除最後一位可用的 Platform admin：嘗試停用最後一位時被拒
- [ ] AuditLog 記錄操作者、操作、對象、時間、結果；日誌內不出現完整證件號、驗證碼或密碼
- [ ] AuditLog 不可刪改：沒有任何 API 能修改或刪除既有稽核紀錄
