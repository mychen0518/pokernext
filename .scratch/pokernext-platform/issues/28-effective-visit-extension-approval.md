# 28: 有效到訪延長申請與審批

**What to build:** 四項證據同時成立（新行程編號＋同趟酒店實際入住＋同趟天城有效報到＋該趟活動日已有天城核准且大於零的打牌新增積分）時系統提出有效到訪延長申請；管理者看到原歸屬人、原期限、四項證據、來源與擬定新期限後核准；新期限取 max(原到期日, 首次有效活動日＋6 個月)，不累加。

**Blocked by:** 14（歸屬指派／轉派、公共池、六個月期限與轉派後可見範圍）、20（現場事實事件與服務生命週期投影）、24（天城每日積分 Excel 匯入、差額預覽、核准入帳與配對）

**Status:** ready-for-agent

- [ ] 四項證據齊備才提出申請；任一缺（例如只有酒店入住沒有天城報到、或積分為 0）不提出（四個反例）
- [ ] 新期限＝max(原到期日, 首次有效活動日＋6 個月)；重複到訪不累加（可控時鐘）
- [ ] 核准前重查歸屬、期限與四證據；同案只生效一次；歸屬已變更時舊申請不套到新歸屬人
- [ ] 延長涉及審批者本人名下獎勵時必須交給另一位授權者（沿用第 04 票）
- [ ] 到期前已有成立的延長申請待審 → 暫緩進池；拒絕且已到期才回池
- [ ] 退房未離島而重新申請的行程不算一次回訪、不再次延長
