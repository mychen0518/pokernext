# 29: 合作績效：公司行銷費、個人業績與獎金結算

**What to build:** 財務按韓國活動日自然月，以全部合作玩家當月打牌新增總分乘以公司約定每分單價計算公司月行銷費；每月 1 日產出上月對帳草稿，核實後送天城；天城對帳角色逐筆核對並確認整期但看不到獎金；對應期全額入帳後才發獎金；員工先確認自己的獎金明細，再由另一位授權者審批支付。

**Blocked by:** 14（歸屬指派／轉派、公共池、六個月期限與轉派後可見範圍）、24（天城每日積分 Excel 匯入、差額預覽、核准入帳與配對）、26（玩家確認結算、正式扣分、住宿兌換核對單與天城「雙方已對齊」）

**Status:** ready-for-agent

- [ ] 月行銷費＝當月打牌新增總分 × 每分單價；玩家住宿扣分不減少行銷費、也不減少已產生業績（一正一反）
- [ ] 每月 1 日自動產出上月草稿（可控時鐘）；核實完整才可送交
- [ ] 天城行銷費對帳角色的回應中不含任何個人獎金欄位
- [ ] 部分來款不按比例發獎；全額入帳後才可支付
- [ ] 員工／Agent 看到已產生未結算業績、已結算未支付獎金、已支付三分區；先本人確認再第二人審批
- [ ] 一般轉派當日的業績歸原歸屬人、次一活動日起歸新歸屬人；公共池期間不計任何人獎金
- [ ] 歷史轉派影響已支付款項時走調整單，不覆寫支付歷史
- [ ] 未定價時保留積分／業績量，不顯示 0 或「可領」

**Notes:** G10：真實單價與生效月份未定，價目為版本化配置；G08：終止合作後未抵完協議未定。
